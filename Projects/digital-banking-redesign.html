Flagship Case Study

Rediseño Digital & Analítica de Producto: Banca Pública

Transformación de extremo a extremo de la plataforma pública bancaria. Integración de gestión de producto ágil (MVP Canvas & User Stories), modelamiento de procesos BPMN 2.0, arquitectura de datos en PostgreSQL, administración con Puck CMS y analítica digital avanzada (GA4 / Clarity).

Product Owner & Business Analyst PostgreSQL & SQL BPMN 2.0 Puck CMS GA4 / Clarity / GTM Rovo AI & GenAI

El Desafío de Negocio

El portal web público legacy presentaba altas tasas de abandono en solicitudes de productos (cuentas/créditos), rigidez operativa para publicar campañas comerciales y falta de telemetría de eventos de usuario.

La Solución de Producto

Liderazgo de triada ágil para migrar a administración No-Code/Low-Code con Puck CMS, maquetación apoyada en IA (Firebase), pruebas QA funcionales en Staging y etiquetado GTM completo.

Impacto Cuantitativo

+35% en conversión de solicitudes digitales, reducción de tiempo de publicación web de semanas a minutos y 100% de calidad probada previo a despliegue productivo.

Propuesta de Valor

Plataforma web pública autónoma y rápida que permite crear y publicar páginas comerciales en minutos con administración Puck CMS, garantizando alta conversión y experiencia UX optimizada.

Métricas Clave de Éxito (KPIs)

  • Tasa de conversión de embudo de captación (% finalizado).
  • Tiempo de publicación web (SLA de días a minutos).
  • Tasa de rebote móvil y mapa de calor (Clarity).

Segmento de Usuarios

Personas y PYMEs en búsqueda de apertura de cuentas corrientes, créditos de consumo y servicios financieros digitales de Banco Internacional.

Canales & Medición

Portal Web Público, Campañas Digitales (GTM), Google Analytics 4 (GA4), Microsoft Clarity y Dashboards en Looker Studio / Power BI.

Consultas SQL en PostgreSQL (Analítica de Producto)

PostgreSQL 15

Extracción de métricas de conversión y comportamiento de usuarios mediante consultas SQL directas sobre la base de datos de eventos digitales (`digital_events`):

1. Análisis de Embudo de Conversión de Productos Financieros

WITH funnel_steps AS ( SELECT session_id, device_category, MAX(CASE WHEN event_name = 'page_view_public' THEN 1 ELSE 0 END) AS step1_landing, MAX(CASE WHEN event_name = 'click_apply_now' THEN 1 ELSE 0 END) AS step2_intent, MAX(CASE WHEN event_name = 'start_form_fill' THEN 1 ELSE 0 END) AS step3_form, MAX(CASE WHEN event_name = 'submit_application_success' THEN 1 ELSE 0 END) AS step4_converted FROM digital_events WHERE event_timestamp >= CURRENT_DATE - INTERVAL '30 days' GROUP BY session_id, device_category ) SELECT device_category, COUNT(session_id) AS total_sessions, SUM(step2_intent) AS intent_clicks, SUM(step4_converted) AS total_conversions, ROUND(SUM(step4_converted)::NUMERIC / COUNT(session_id) * 100, 2) AS overall_conversion_pct FROM funnel_steps GROUP BY device_category ORDER BY overall_conversion_pct DESC;

2. Rendimiento de Páginas Publicadas en Puck CMS vs. Legacy

SELECT page_cms_type, COUNT(DISTINCT session_id) AS unique_visitors, ROUND(AVG(page_load_time_ms), 0) AS avg_load_time_ms, ROUND(SUM(conversion_flag)::NUMERIC / COUNT(session_id) * 100, 2) AS conversion_rate FROM web_performance_logs WHERE log_date >= '2025-01-01' GROUP BY page_cms_type;
