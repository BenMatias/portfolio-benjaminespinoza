Competitive Gaming Analytics & Objectives

PokéAPI REST v2 Service

The Pokémon franchise spans 9 generations, evolving from 151 original creatures into a complex competitive ecosystem of 1,025 distinct species. Each Pokémon is defined across 6 fundamental combat stats (HP, Attack, Defense, Special Attack, Special Defense, Speed) and can possess single or dual elemental typing.

This business intelligence project transforms raw game telemetry extracted via the PokéAPI into a structured analytics portal. The analytical objective is to enable deep comparison of attribute distributions, benchmark generation stat creep, and uncover dominant type combinations.

Apps Script ETL Pipeline

An automated Google Apps Script pipeline fetches and parses paginated JSON payloads from PokéAPI v2, storing the normalized dataset into Google Sheets before serving it to Looker Studio:

Fact_Pokemon_Stats

  • PokedexNumber (PK) INT [1..1025]
  • PrimaryTypeKey (FK) VARCHAR(12)
  • SecondaryTypeKey (FK) VARCHAR(12)
  • GenerationKey (FK) TINYINT
  • BaseStatTotal (BST) SMALLINT
  • HP / Attack / Defense TINYINT
  • SpAttack / SpDef / Speed TINYINT
  • IsLegendary / IsMythical BOOLEAN

Dim_Elemental_Type

  • TypeKey (PK) VARCHAR(12)
  • TypeName VARCHAR(15)
  • TypeColorHex CHAR(7)
  • WeaknessCount TINYINT
  • ResistanceCount TINYINT

Dim_Generation

  • GenerationKey (PK) TINYINT [1..9]
  • RegionName VARCHAR(20)
  • ReleaseYear SMALLINT
  • TotalSpeciesIntroduced SMALLINT

Google Apps Script ETL Automation

Custom JavaScript ETL script running on Google Apps Script to fetch and format API records: 

function fetchNationalPokedex() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Pokedex_Master");
  const baseUrl = "https://pokeapi.co/api/v2/pokemon?limit=1025";
  const response = UrlFetchApp.fetch(baseUrl);
  const data = JSON.parse(response.getContentText()).results;
  
  // Transform and load parsed stats into normalized tabular format
  const rows = data.map((pokemon, index) => {
    const detail = JSON.parse(UrlFetchApp.fetch(pokemon.url).getContentText());
    return [
      detail.id,
      detail.name,
      detail.types[0]?.type?.name || "None",
      detail.types[1]?.type?.name || "None",
      detail.stats.reduce((acc, s) => acc + s.base_stat, 0), // BST
      detail.stats[0].base_stat, // HP
      detail.stats[1].base_stat, // Attack
      detail.stats[2].base_stat, // Defense
      detail.stats[3].base_stat, // Special Attack
      detail.stats[4].base_stat, // Special Defense
      detail.stats[5].base_stat  // Speed
    ];
  });
  sheet.getRange(2, 1, rows.length, rows[0].length).setValues(rows);
}

Game Balance & Meta Stat Findings

Design Analytics

Statistical evaluation of the complete 1,025 species roster reveals four key insights into franchise game balance evolution:

1. Multi-Generational Stat Creep

Average non-legendary Base Stat Total increased from 407 in Generation 1 (Kanto) to 486 in Generation 9 (Paldea), reflecting a systematic upward progression in offensive baseline viability.

2. Steel & Fairy Defensive Dominance

Steel-type dual pairings boast the highest average defensive ratings across all 18 types (avg Defense 98.4), with Steel/Fairy remaining the most statistically resilient defensive pairing in the meta.

3. Speed Tier Polarization

Speed distributions demonstrate bimodal polarization in modern generations: species are heavily clustered either below 50 Speed (Trick Room archetypes) or above 110 Speed (fast sweepers).

4. Extreme Min-Maxing in Modern Meta

Recent generations exhibit lower stat variance within single attributes, favoring hyper-specialized combat roles ('glass cannons' or 'pure physical walls') over balanced generalist spreads.
