NASA Planetary Defense & Telemetry Objectives

NASA JPL Center for NEO Studies (CNEOS)

Near-Earth Objects (NEOs) are comets and asteroids whose orbits bring them into proximity with Earth's orbit (within 1.3 Astronomical Units). NASA's Planetary Defense Coordination Office continuously surveys these celestial bodies to evaluate collision probabilities and kinetic energy profiles.

This business intelligence project ingests raw JSON feeds from the NASA NeoWs (Near Earth Object Web Service) API. The analytical objective is to structure a scalable reporting layer that calculates hazard ratios, diameter confidence intervals, and close approach velocity distributions in real time.

Aerospace Data Model (Star Schema)

Dimensional Telemetry Architecture

Nested JSON payloads from the NeoWs feed were flattened and transformed into a Power BI Star Schema separating physical asteroid dimensions from temporal close-approach events:

Fact_Close_Approaches

  • NeoId (FK) INT
  • DateKey (FK) INT [YYYYMMDD]
  • RelativeVelocity_KMH DECIMAL(12,2)
  • RelativeVelocity_KMS DECIMAL(6,3)
  • MissDistance_KM BIGINT
  • MissDistance_LD DECIMAL(8,4)
  • OrbitingBody VARCHAR(10)

Dim_Near_Earth_Object

  • NeoId (PK) INT
  • Name VARCHAR(50)
  • AbsoluteMagnitude_H DECIMAL(5,2)
  • EstDiameterMin_M DECIMAL(8,2)
  • EstDiameterMax_M DECIMAL(8,2)
  • IsHazardous_PHA BOOLEAN
  • NasaJplUrl VARCHAR(150)

Dim_Approach_Date

  • DateKey (PK) INT [YYYYMMDD]
  • DateValue DATE
  • Year / Month INT / VARCHAR
  • WeekNumber TINYINT
  • DayOfWeek VARCHAR(10)

Kinematic & Risk DAX Measures

Formulas engineered in DAX to compute estimated mean diameter, hazardous object ratios, and minimum lunar proximity: 

-- DAX: Estimated Mean Asteroid Diameter (Meters)
Est_Mean_Diameter_M = 
AVERAGEX(
    Dim_Near_Earth_Object,
    (Dim_Near_Earth_Object[EstDiameterMin_M] + Dim_Near_Earth_Object[EstDiameterMax_M]) / 2
)

-- DAX: Percentage of Potentially Hazardous Asteroids (PHA Rate)
PHA_Hazard_Ratio_Pct = 
DIVIDE(
    CALCULATE(COUNTROWS(Dim_Near_Earth_Object), Dim_Near_Earth_Object[IsHazardous_PHA] = TRUE()),
    COUNTROWS(Dim_Near_Earth_Object),
    0
) * 100

-- DAX: Closest Approach Distance in Lunar Distances (LD)
Closest_Approach_LD = MIN(Fact_Close_Approaches[MissDistance_LD])

Astronomical Telemetry & Risk Findings

Planetary Defense Analytics

Quantitative synthesis of the NEO telemetry data reveals four core takeaways regarding orbital risk distributions:

1. Kinetic Velocity vs. Diameter Distribution

The vast majority of detected NEOs (85%+) measure under 100 meters in diameter, exhibiting hypervelocity approaches between 40,000 km/h and 110,000 km/h relative to Earth's barycenter.

2. PHA Hazard Ratio Baseline

Potentially Hazardous Asteroids (PHAs) constitute approximately 8% to 12% of tracked weekly objects, with the majority maintaining comfortable safety buffers exceeding 10 Lunar Distances (3.8M+ km).

3. Absolute Magnitude (H) Inverse Law

Visualizing absolute magnitude against estimated diameter confirmed the inverse logarithmic scaling: objects with H > 24 consistently correlate with sub-50-meter rock fragments.

4. Automated REST ETL Resilience

The decoupled JSON parser and Star Schema architecture ensure zero data degradation even when NASA API responses contain variable daily object counts or missing albedo parameters.
